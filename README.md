## Resumen

El objetivo de este documento es presentar, a través de ejemplos, los conceptos fundamentales de **Spring MVC**, un marco web de Java basado en el patrón **MVC (Modelo-Vista-Controlador)**.

Spring MVC forma parte del ecosistema **Spring Framework** y proporciona un marco estructurado para desarrollar aplicaciones web en Java robustas y fáciles de mantener.

El curso también presenta **Thymeleaf**, un motor de vistas moderno y potente que se integra especialmente bien con Spring MVC.

## Destinatarios

Este curso está dirigido a lectores con un **buen dominio del lenguaje Java**.

**No se requieren conocimientos previos de programación web**, ya que los conceptos se introducen de forma gradual.

## Alcance del documento

Aunque es relativamente detallado, este documento no pretende ser exhaustivo.
Spring es un marco de trabajo muy amplio, compuesto por numerosos componentes y extensiones.

El documento se ha diseñado para **leerse sin necesidad de un ordenador**, lo que explica la presencia de numerosas **capturas de pantalla**.
