    5. Vistas de Thymeleaf

    Volvamos a la arquitectura de una aplicación Spring MVC.

    En los dos capítulos anteriores se describieron diversos aspectos del bloque [1], las acciones. Ahora abordaremos:

    • el bloque [2] de las vistas V;
    • el modelo [3] (M) que muestran estas vistas;

    Desde la creación de Spring MVC, la tecnología utilizada para generar las páginas HTML enviadas a los navegadores de los clientes ha sido JSP (Java Server Pages). En los últimos años, también ha surgido la tecnología [Thymeleaf] [http://www.thymeleaf.org/]. A continuación, presentaremos esta tecnología.

    5.2. [/v01]: Conceptos básicos de Thymeleaf

    Veremos la siguiente acción en [ViewsController]:

    
    // thymeleaf basics - 1
    @RequestMapping(value = "/v01", method = RequestMethod.GET)
    public String v01() {
        return "v01";
}
    • Línea 3: La acción devuelve un tipo [String]. Este será el nombre de la acción;
    • línea 4: esta vista será [v01]. Por defecto, debe estar ubicada en la carpeta [templates] y llamarse [v01.html];

    La vista [v01.html] es la siguiente:

    
<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
<title th:text="'Les vues'">Spring 4 MVC</title>
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
</head>
<body>
    <h2 th:text="'Les vues dans Spring MVC'">Spring 4 MVC</h2>
</body>
</html>

    Este es un archivo HTML. La presencia de Thymeleaf es evidente:

    • en el espacio de nombres [th] de la línea 2;
    • en los atributos [th:text] de las líneas 4 y 8;

    Este es un archivo HTML válido que se puede visualizar. Lo colocamos en la carpeta [static] [2] con el nombre [vue-01.html] y accedemos a él directamente mediante un navegador:

    Si examinamos el código fuente de la página en [2], podemos ver que los atributos [th:text] fueron enviados por el servidor e ignorados por el navegador. Cuando una vista es el resultado de una acción, Thymeleaf entra en acción e interpreta los atributos [th] antes de enviar la respuesta al cliente.

    La etiqueta HTML:

    
<title th:text="'Les vues'">Spring 4 MVC</title>

    es procesada de la siguiente manera por Thymeleaf:

    • th:text tiene la sintaxis th:text="expresión", donde expresión es una expresión que se va a evaluar. Cuando esta expresión es una cadena, como en este caso, debe ir entre comillas simples;
    • el valor de [expresión] sustituye al texto de la etiqueta HTML, en este caso el texto de la etiqueta [title];

    Tras el procesamiento, la etiqueta anterior queda así:

    
<title>Les vues</title>

    5.6. [/v06]: Pruebas en una vista de Thymeleaf

    Consideremos la siguiente acción [/v06]:

    
    // creation of the M model of a V - 3 view
    @RequestMapping(value = "/v06", method = RequestMethod.GET)

<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
    <head>
        <title th:text="#{title}">Spring 4 MVC</title>
        <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
    </head>
    <body>
        <div th:object="${personne}">
            <p>
                <span th:text="#{personne.nom}">Nom :</span>
                <span th:text="*{nom}">Bill</span>
            </p>
            <p>
                <span th:text="#{personne.age}">Age :</span>
                <span th:text="*{age}">56</span>
            </p>
            <p th:if="*{age} >= 18" th:text="#{personne.majeure}">Vous êtes majeur</p>
            <p th:if="*{age} &lt; 18" th:text="#{personne.mineure}">Vous êtes mineur</p>
        </div>
    </body>
</html>
    • Línea 17: El atributo [th:if] evalúa una expresión booleana. Si esta expresión es verdadera, se muestra la etiqueta; de lo contrario, no. Así pues, aquí, si ${person.age} >= 18, se mostrará el texto [#{person.majeure}], es decir, la clave de mensaje [person.majeure] de los archivos de mensajes;
    • línea 18: no se puede escribir [*{age} < 18] porque el signo < es un carácter reservado. Por lo tanto, debe utilizarse su equivalente HTML [&lt;], también conocido como la entidad HTML [http://en.wikipedia.org/wiki/List_of_XML_and_HTML_character_entity_references];
